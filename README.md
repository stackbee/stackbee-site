# stackbee-site

株式会社スタックビーのコーポレートサイト。**会社概要**と**電子公告**を掲載する。

公開URL: https://stack-bee.io/

---

## ⚠️ このサイトの重要性

`/koukoku/` は **登記簿に記載された法的な公告掲載先**である。

履歴事項全部証明書の「公告をする方法」に `https://stack-bee.io/koukoku/` が記載されており、
定款第4条にも同様の定めがある。**このページが恒常的に閲覧できない状態は、公告義務の履行に影響する。**

URL を変更する場合は**変更登記が必要**になるため、パスは動かさないこと。

---

## 構成

```
index.html          会社概要・事業内容
koukoku/index.html  電子公告
privacy/index.html  プライバシーポリシー（アクセス解析の外部送信を含む）
assets/style.css    スタイル（外部依存なし）
CNAME               カスタムドメイン設定（stack-bee.io）
```

外部のCDN・フォント・JSライブラリに依存していない。可用性を他サービスに預けないための意図的な設計。

**例外：アクセス解析（Google アナリティクス）のタグだけは Google から読み込む。**
タグは非同期で読み込むので、Google 側が止まってもページの表示と電子公告（`/koukoku/`）の閲覧には影響しない。
導入の経緯と判断は `stackbee/biz-repo` の Issue #76 にある。外部依存をこれ以上増やさないこと。

## 公開の仕組み

- **ホスティング**: GitHub Pages（`main` ブランチのルート）
- **ドメイン**: `stack-bee.io`（レジストラは **Squarespace Domains**。Google Workspace 契約時に同時取得）
- **HTTPS**: GitHub Pages が Let's Encrypt で自動発行

### DNS

`stack-bee.io` は **Google Workspace のメールでも使用している**。

> ⚠️ **MX レコードは絶対に触らないこと。** 削除すると会社のメールが停止する。
> GitHub Pages 用に変更するのは **A レコード**と **CNAME（www）**のみ。

## 更新のしかた

### 方法1: ブラウザだけで更新（Gitの知識が不要）

1. GitHub でこのリポジトリを開く
2. 編集したいファイル（例: `koukoku/index.html`）をクリック
3. 鉛筆アイコン → 編集 → **Commit changes**
4. 1〜2分で https://stack-bee.io/ に反映される

### 方法2: ローカルから

```bash
git clone https://github.com/stackbee/stackbee-site.git
# 編集
git commit -am "update"
git push
```

## 決算公告の掲載手順

> 以下は 2026-07-29 に顧問税理士（エクセライク会計事務所 岡野氏）へ確認した内容。

| 項目 | 内容 |
|---|---|
| 掲載内容 | **貸借対照表の全文**（電子公告のため「要旨」では足りない） |
| 掲載時期 | 定時株主総会の終結後、遅滞なく。実務上は総会から**2週間以内**が目安 |
| **掲載期間** | **5年間、継続して掲載し続ける必要がある** |
| 第1期の初回目安 | **2027年9月14日**（申告期限 2027/8/31 の2週間後） |

第1期は 2026年7月10日 ～ 2027年6月30日。

1. `koukoku/index.html` の「掲載中の公告はありません」のブロックを、**貸借対照表の全文**に差し替える
2. 掲載開始日を明記する
3. **5年間は消さない**（`/koukoku/` のパスも変えない。登記簿に記載されたURLのため）

### 【決定】決算公告は掲載しない（2026-07-29）

**方針：決算公告は行わない。ただし本ページ自体は維持する。**

顧問税理士（エクセライク会計事務所 岡野氏）の見解は次のとおり。

> 会社法上は義務（怠ると100万円以下の過料の対象）だが、実務上は非上場の中小企業のほとんどが決算公告を行っておらず、それ単独の理由で過料を受けた事例も聞かない。**実務運用上の結論として、公告の掲載は不要。**

これに従う。判断の根拠は以下。

**掲載しない側の理由**
- 実際に決算公告を見に行く場面がほぼない。金融機関は**決算書そのものを提出させる**し、取引先の与信は信用調査会社のデータを使う
- **一度掲載すると5年間消せない**。継続義務を自ら背負うことになり、途中でやめるのは最初からやらないより印象が悪い
- **貸借対照表が公開される**。1人法人では現預金・借入金・繰越利益がそのまま見える。債務超過の年も公開対象になる

**掲載する側の理由（採用しなかった）**
- サイトが既にあるため掲載コストはほぼゼロ（官報と違い年約6万円の節約は発生しないので、費用面では「やらない理由」もない）
- 電子公告は登記簿にURLが載るため、官報より「掲載していない」ことの可視性が高い

→ 可視性は事実だが、**実際に閲覧される場面が乏しい**ため決め手にならないと判断した。

### ⚠️ このページ自体は残すこと

掲載しない方針でも、**`/koukoku/` が 404 になってはいけない**。URLは登記簿に公示されているため、開いてエラーが返ると会社の管理体制を疑われる。

現在の「**現在、掲載中の公告はありません**」という表示のまま維持する。

### 再判断のタイミング

**2027年夏（第1期決算時）** に改めて判断する。状況が変われば掲載する選択も残す。
